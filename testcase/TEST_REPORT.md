## 技术分析

### 互通性关键要点

1. **SM2 加密格式**：所有语言统一使用 **C1C3C2** 格式（国密标准规定）
2. **SM2 签名格式**：统一使用 **ASN.1 DER** 编码，USER_ID="1234567812345678"
3. **SM2 密钥格式**：公钥使用 X.509 SPKI DER，私钥使用 PKCS#8 DER
4. **SM4 GCM 参数**：IV=12字节，Tag=16字节，密钥=16字节，无 AAD
5. **编码格式**：所有语言 Hex 优先，同时支持 Base64，UTF-8 文本编码
6. **SM4 模式**：已统一为 GCM 模式，删除 ECB 遗留代码

### 测试数据（Python 生成）

| 操作 | 示例输出 |
|------|---------|
| SM2 密文 (Hex) | 长度约 290 hex chars (145 bytes = 65+32+可变) |
| SM2 签名 (DER Hex) | 长度约 140-144 hex chars (70-72 bytes) |
| SM3 摘要 (Hex) | `0880efb46176002c6cd1d94bcc3d9d9161488e099317d34a4d6b28b7becef36b` |
| SM3-HMAC (Hex) | `3e0c629ac18e2ad27415a549707565b0063872d65384e88ee2d1f88735b280f6` |
| SM4 GCM 密文 (Hex) | IV(12) + 密文 + Tag(16) = 28+明文长度 |
