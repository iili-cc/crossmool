## 一、v2→v3 变更摘要

| 变更 | 说明 |
|------|------|
| ✅ FIX-011 | 修复 Python SM2 C1C3C2 加密 04 前缀问题 |
| ✅ Go↔Python SM2 E/D | 由 ❌ 变为 ✅ (双向互通) |
| ✅ 全部 6 项操作 | Go↔Python 全部通过 |

**根本原因**: Python gmssl 的 `CryptSM2.encrypt()` 返回 64 字节 C1（不含 04 前缀），而 Go/Java 标准 C1C3C2 使用 65 字节 C1（含 04 前缀）。

**修复方案**: Python `encrypt_to_hex` 补上 04 前缀，`decrypt_from_hex` 自动检测并去除 04 前缀。

## 五、修复记录 (v2→v3 新增)

### FIX-011: Python SM2 C1C3C2 04前缀修复

| 项目 | 详情 |
|------|------|
| 文件 | `python/crossmool/src/sm2_util.py` |
| 问题 | gmssl 的 encrypt 返回 64 字节 C1 (X+Y)，缺少 04 未压缩点前缀 |
| 标准 | C1C3C2 中 C1 应为 65 字节 (04+X+Y)，Go/Java/BouncyCastle 均使用此格式 |
| 修复 | `encrypt_to_hex`: 补上 04 前缀; `decrypt_from_hex`: 自动检测并去除 04 前缀 |
| 影响 | Go↔Python SM2 加密解密从 ❌ 变为 ✅ |
