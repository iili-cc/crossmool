## 六、互操作性标准约定

### SM2
- 密文: C1C3C2格式 + 04前缀(65+32+N 字节)
- 签名: DER ASN.1 Sequence { INTEGER r, INTEGER s }
- USER_ID: "1234567812345678"

### SM3
- 输出: 32字节/64 HEX字符
- 预期: `0880efb46176002c6cd1d94bcc3d9d9161488e099317d34a4d6b28b7becef36b`
- HMAC密钥: `01020304...1f20` (32字节)
- HMAC预期: `3e0c629ac18e2ad27415a549707565b0063872d65384e88ee2d1f88735b280f6`

### SM4 GCM
- IV: 12字节 | Tag: 16字节
- 输出: IV + 密文 + Tag (Hex, 默认)
- 测试密钥: `0123456789abcdeffedcba9876543210`
