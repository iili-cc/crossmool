## 五、互操作性标准约定

为确保8种编程语言的国密算法实现可以无缝互通，各方必须遵守以下约定：

### SM2 加密
- **密文格式**: C1C3C2
- **C1格式**: 04 + X(32字节) + Y(32字节) = 65字节/130 HEX字符
- **编码**: Hex优先, 同时支持Base64

### SM2 签名
- **签名格式**: DER ASN.1 Sequence { INTEGER r, INTEGER s }
- **签名算法**: SM2Signer with SM3 hash
- **USER_ID**: "1234567812345678" (GB/T 32918标准默认值)

### SM3
- **输出**: 32字节/64位HEX字符
- **确定性算法**: 相同输入必须产生相同摘要

### SM3-HMAC
- **HMAC密钥**: 任意长度 (建议 >= 32字节)
- **输出**: 32字节/64位HEX字符
- **标准**: 遵循 RFC 2104 HMAC 规范

### SM4 GCM
- **模式**: GCM (NIST SP 800-38D)
- **IV大小**: 12字节 (96 bits)
- **Tag大小**: 16字节 (128 bits)
- **输出格式**: IV[12] + 密文 + Tag[16]
- **编码**: Hex优先, 同时支持Base64
